กติกา 4 ข้อของคู่มือชุดนี้

✓

1 · ทุกเวอร์ชันมาจาก versions.env เท่านั้น รันบรรทัดนี้ก่อนเริ่มทุก session บนทุกเครื่อง — ถ้าลืม คำสั่งจะ error ทันทีเพราะตัวแปรว่าง ซึ่งดีกว่าเผลอไปติดตั้งเวอร์ชันผิด

2 · ทุกคำสั่งมี "ผลลัพธ์ที่ควรเห็น" ถ้าผลไม่ตรง ให้หยุดตรงนั้น อย่าไปต่อแล้วค่อยกลับมาแก้

3 · ไม่มีความลับในไฟล์นี้ password, token และ key ทั้งหมดเป็น placeholder ค่าจริงอยู่ในที่เก็บ secret แยก

4 · ห้าม kubectl edit บน cluster ตรง ๆ ทุกอย่างที่ apply ต้องมาจากไฟล์ใน git เพราะเราไม่มี GitOps มาบังคับให้

ความจริงสองข้อที่ส่งผลกับทุกอย่างหลังจากนี้

✓

ไม่มี Ksplice — ใช้ Oracle Linux แบบฟรี จึงปะ kernel โดยไม่ reboot ไม่ได้ แปลว่าต้อง drain ทุก node ทุก 1-2 เดือน ผลคือ ทุก Deployment ต้องมี PodDisruptionBudget และ replica ≥ 2 ไม่ใช่ข้อแนะนำแต่เป็นข้อบังคับ

Cilium ถือ 3 หน้าที่พร้อมกัน — CNI + kube-proxy + LB-IPAM ทำให้ชิ้นส่วนน้อยลงมาก แต่แลกมาด้วยว่า Cilium มีปัญหาทีเดียว pod network, Service และ LoadBalancer ดับพร้อมกัน และ ไม่มี kube-proxy ให้ถอยกลับไปใช้ เพราะไม่ได้ติดตั้งไว้เลย

capacity ที่ใช้ได้จริง

✓

worker รวมกันได้ 48 vCPU / 144 GB แต่วางแผนได้แค่ 32 vCPU / 96 GB เพราะเวลา drain หนึ่งเครื่องจะเหลือ worker ทำงาน 2 ตัว
